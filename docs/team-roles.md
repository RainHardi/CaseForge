## 2. Team Responsibilities

The team will follow these principles:
- Each major task should have an owner.
- Each task should have a clear expected result.
- Team members should communicate if they are blocked or cannot meet a deadline.
- Important code changes should be reviewed by another team member.
- Documentation should be updated when important features change.
- Tests should be updated when the system changes.
- Each member should contribute information about their own work to the README and presentation.
- Roles can be adjusted if the workload changes during development.
